GraphQL Basics — Apollo Client

Every button below sends POST http://localhost:8008/graphql. Only the GraphQL document changes.

Start the server first: python graphql_server.py. Open your browser devtools Network tab and watch the graphql requests as you click — the URL and the HTTP method are identical every time.

4. Update employee — updateEmployee mutation

  more advanced topic and are deliberately left out.






  
  
  
  
  
  
  
  








5. Delete employee — deleteEmployee mutation



  Returns a plain Boolean, so the operation has no selection set:
  true if a row was deleted, false if that id did not exist.
